## 按影响排序

1. Windows 窗口：最大化/还原、可访问名称、原生拖动/双击/贴靠/系统菜单、工作区和恢复尺寸。
2. 启动器专属联机：删除导航、房间/P2P/EasyTier 专属页面/状态；保留原生多人、服务器、认证、HTTP 代理和未知历史字段。
3. Java 工具：共用设置中的信任服务，明确路径、只读诊断、独立修复、验证、选用与回退。
4. 图标/字体/输入行高与各页滚动、空态、弹层、错误与取消。
5. Windows 正版缓存兼容、刷新、所有权、真实主菜单/Quit、重启状态；凭据不进入证据。
6. 全页功能、旧数据往返与互斥、下载恢复、打包及跨平台门禁。

## 短预检与首次失败

- 锁定 SDK 10.0.403 已在任务 tools 下恢复；官方 SHA-512 匹配。Avalonia 保持 12.1.5。全局 SDK、Java 与 PATH 不变。
- 重任务由本地控制器串行执行：20 GiB 系统余量、35 GiB 任务预算、20 分钟期限；保留首次日志/TRX，超时/取消仅清理自有进程树。
- 首次 Desktop：100 通过、15 失败；修正 Mac 绝对路径夹具后剩 3 失败。进一步发现原生世界身份 API 不接受长路径；修正后 115/115 通过。
- 首次 Core：321 通过、10 失败、18 显式跳过；包含测试 JDK 17/21 差异、Windows 文件系统异常类型、测试 injector 路径及 Windows 10 原生 ChaCha20-Poly1305 不可用。首次结果均保留，后续结果另记。
- 使用正式 Publish-Desktop.ps1 生成 win-x64 Release 自包含预检候选；该包记录交接 HEAD 与 dirty=true（测试夹具改动），不作为已冻结阶段包。
- 原生新配置首页两卡/四选项与 880×560 DIP 均已截图。通过设置界面保存隐藏偏好后，重启两卡仍隐藏；两次正常关窗。
- 旧 WPF 可执行文件复制到隔离观察目录后实际打开，能读到系统上的旧账户外观；未执行登录/游戏/配置修改，随后正常关闭。不能声称该观察程序完全隔绝全局旧配置读取。
- Mac 当前不可用：所有改动后的 Mac 原生行为待验，既有 R6 RC3 证据保留。
