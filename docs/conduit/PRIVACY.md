# 潮涌核心社启动器：网络与数据使用说明

本说明对应当前开发源码，已发布版本可能仍采用旧行为，需以实际版本为准。

## 遥测与日志

启动器已移除 Sentry 设备调查、错误自动上报、联机集中信息上报，以及原 PCL-CE 服务器的远程联机功能开关。旧遥测配置仅保留用于清除旧授权，不再启用数据发送。

诊断日志保存在本机，可能包含启动参数、目录、服务器地址和本地设备识别码。设备识别码仍用于本地兼容处理；账户加密方式没有随本次联机改造改变。用户选择分享日志或崩溃报告时，应先检查其中的个人信息。

## 联机

大厅不再需要 Natayark 账户，也不自动刷新旧 Natayark 令牌。联机昵称来自本机设置或当前游戏账户；自定义节点来自本机设置。启用公共节点时，启动器使用内置的 EasyTier 公共节点地址，不再下载原项目的远程策略或中继列表。EasyTier 程序从其官方 GitHub Releases 下载。

建立联机连接时，节点运营方和其他参与者可能接触到必要的 IP 地址、昵称、连接状态和大厅信息。联机协议使用本次启动随机生成的会话标识，不再发送本机硬件派生识别码。公共节点由第三方运营，其可用性及数据处理不由本项目控制；可以选择“仅使用自定义节点”。

## 登录、下载与在线内容

- 微软、LittleSkin、MUA 或用户指定的认证服务按用户选择处理登录请求；密码和令牌不发送给社团代码仓库。
- Minecraft、模组、整合包与加载器下载会联系所选官方服务或镜像。下载服务可见请求的资源、网络地址和启动器版本标识。
- DoH 默认使用 doh.pub 与 Cloudflare；域名解析服务可接收到查询域名。可在网络设置中关闭 DoH。
- 自定义在线主页及其他在线预设仍由相应站点提供内容；选择前应确认来源可信。旧 CE 公告栏预设会迁移到默认主页。
- 社团更新检查访问本仓库 GitHub Releases；启动器不会通过原项目更新源自动替换程序。
