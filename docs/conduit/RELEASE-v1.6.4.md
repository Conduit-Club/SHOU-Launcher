# 潮涌核心社启动器 v1.6.4 · mcp

本版将新版桌面启动器纳入正式发行，适用于 Windows 和 Apple Silicon Mac。已有实例可以继续使用，启动器会校验并复用旧目录里的游戏文件。

## 启动和下载

- 头像和皮肤在后台加载。有可用账号和实例时，可直接点击「启动游戏」。准备游戏期间也可以浏览下载、切换页面或编辑设置。
- 启动进度显示在启动按钮处。Java 进程接手后恢复「启动游戏」按钮。
- 延续新版的整合包导入与导出、实例资源管理和 aria2 接入。内置下载支持对具有已知大小和哈希的大文件进行分段下载，并校验续传或复用的文件。

## MCP 接入

在「工具 → MCP」设置本机端口并启动服务。页面可以复制连接地址和本次会话的令牌，也可以导出包含 Codex 和 Claude Code 配置示例的 Agent 技能。服务每次打开启动器时默认为暂停。

连接后，Agent 可检查和接入游戏目录、管理实例与版本、下载整合包和资源包、选择 Java，以及分析实例的最新崩溃日志。需要手动补充文件的 CurseForge 整合包可在启动器的下载页处理。

## 选择下载包

| 设备 | 下载文件 |
| --- | --- |
| Windows（Intel 或 AMD） | `SHOU-Launcher-win-x64-v1.6.4.zip` |
| Windows ARM64 | `SHOU-Launcher-win-arm64-v1.6.4.zip` |
| Apple Silicon Mac | `SHOU-Launcher-osx-arm64-v1.6.4.zip` |

Windows 更新时先退出启动器，再把解压后的 EXE 放回原目录。macOS 更新时先退出旧版，再将解压后的「SHOU Launcher.app」放入「应用程序」替换。首次迁移旧账户时，macOS 可能提示授权钥匙串。

各包的 SHA-256 可在 GitHub 下载附件中查看。遇到问题可通过启动器的「反馈」页面提交。
