# R42：资源包与光影包更新（2026-11-12）

本轮延续 `features/windows-parity`，对照旧 WPF `PageInstanceCompResource.UpdateResource` 的共同资源列表行为，在独立 Core/Avalonia 实现资源包、光影包更新。旧 WPF 源码、个人应用及个人实例保持不变；未启动 Minecraft。

## 本轮功能

- 进入资源包或光影页自动检查，不弹全页遮挡；按已安装文件的 SHA-1、SHA-512、大小及安装来源核对身份。支持 Modrinth 哈希识别与 CurseForge 来源/指纹识别；无法核实的文件保留本地信息，不计作最新版。
- 按项目类型和当前游戏版本查正式版更新；资源包/光影不套用实例的 Fabric/Forge 加载器条件。自动检查使用六小时缓存，手动重查绕过缓存；检查进度、取消、超时及迟到结果保护复用现有流程。
- “可更新”计数与筛选、名称旁更新箭头、右下“更新所选”均接入真实更新令牌。资源包/光影点击后直接更新，模组继续保留原警告；某项失败会记录并继续余项。
- 先下载校验，再备份原压缩包与精确原安装清单，最后替换和提交清单；错误、取消或目标变化回滚。备份位于实例 `.shou-resource-backups`；原有模组备份目录保持。
- 保留所选资源在实例中的文件名，避免资源包启用列表及 Iris/OptiFine 光影引用失效；显示版本来自已核实的在线文件身份，不通过改文件名猜版本。
- 按旧 WPF 的所选资源更新范围，仅替换所选压缩包，不顺带安装或升级依赖模组。依赖声明保留在详情，完成提示说明本次范围；不把声明当成完整兼容分析。
- 更新后筛选归零显示“当前筛选下没有可更新的资源”，不再误称实例没有资源。新增静态提示维护简体中文、繁體中文、English。
