# 潮涌核心社启动器 v1.6.2 · xb

本次预发布修复点击启动后，启动器已结束加载、游戏窗口却尚未出现的等待体验。

## 本次修复

- Java 启动后继续显示游戏初始化状态和等待秒数，确认游戏窗口出现后再结束启动进度。
- 初始化期间可点击「返回启动器」继续使用其他功能，游戏仍会在后台启动；保留同一整合包多开窗口的能力。
- 启动后的自动最小化、隐藏或关闭，改为在游戏窗口出现后执行。
- 修正多个游戏正在启动时的状态交接，避免较早启动的进程覆盖当前进度。

本次主要改善等待提示和窗口交接。游戏本身的加载时间仍取决于整合包、Java、设备和图形初始化。

## 选择下载包

| 设备 | 下载文件 |
| --- | --- |
| 常规 Windows 电脑（Intel / AMD） | `SHOU-Launcher-win-x64-v1.6.2.zip` |
| Windows ARM64 设备 | `SHOU-Launcher-win-arm64-v1.6.2.zip` |
| Mac M 系列芯片 | `SHOU-Launcher-osx-arm64-v1.6.2.zip` |

Windows：退出启动器后解压，将新 EXE 放回原目录。无需另装 .NET，可继续使用原实例和同一 Windows 用户保存的账户。

macOS：退出旧版，将解压后的「SHOU Launcher.app」放入「应用程序」替换。沿用已保存的实例和账户；首次迁移旧账户时，可能需要按系统提示完成一次钥匙串授权。

## 使用提示

- 这是预发布版本，部分旧整合包和设备适配仍在完善；目前不提供 Intel Mac 版本。
- Mac 唤醒或切换显示器后若偶发无法打开窗口，请待桌面恢复后重新打开。
- Mac 版尚未通过 Apple 公证，Windows 版暂未提供数字签名，首次运行可能出现系统安全提示。
- 下载附件仅提供三个平台的编译包；文件 SHA-256 可直接在 GitHub 查看。

遇到问题可通过启动器的「反馈」页面提交。
