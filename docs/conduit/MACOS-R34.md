## 自动保存

移除设置页底部保存、放弃和草稿状态条。有效编辑合并 350 ms 后自动写入，关闭前补写；输入错误在页面内提示，保留上次有效配置，不跳转页面或弹阻塞对话框。实例和存档的显式保存流程保留，关闭时仍提醒未保存修改。

每次写入先捕获不可变配置和界面偏好，串行保存；保存期间的新编辑留待下一次写入，不用较旧回调覆盖。凭据通过安全存储，密码输入失焦才更新绑定，失败保留输入以便重试、提示不回显密钥。默认 Java 被工具更改时，仍保留冲突选择，避免较早的设置覆盖新的安全副本。工具操作不强制提交无关未完成设置；aria2 连接测试会先保存有效连接参数，仍遵守本机端口优先和内置回退。
