# 潮涌核心社启动器 v1.6.1 · xb

本次预发布重点修复旧版本迁移后的资源重复下载和首页头像读取问题。

## 本次修复

- 接入旧实例后，校验并复用已有客户端、依赖库、资源索引和资源文件，只补充缺失或损坏的文件，减少重复下载。
- 首页自动恢复已保存的在线账户，必要时刷新登录，再加载头像、皮肤和披风，无需先启动游戏。
- 修复令牌刷新时头像请求被中断的问题；认证失败会保留账户并提示重新登录，不会循环重试。
- 精简下载附件，仅提供三个平台的启动器编译包；文件 SHA-256 可直接在 GitHub 查看。

## 选择下载包

| 设备 | 下载文件 |
| --- | --- |
| 常规 Windows 电脑（Intel / AMD） | `SHOU-Launcher-win-x64-v1.6.1.zip` |
| Windows ARM64 设备 | `SHOU-Launcher-win-arm64-v1.6.1.zip` |
| Mac M 系列芯片 | `SHOU-Launcher-osx-arm64-v1.6.1.zip` |

Windows：退出启动器后解压，将新 EXE 放回原目录。无需另装 .NET，可继续使用原实例和同一 Windows 用户保存的账户。

macOS：退出旧版，将解压后的「SHOU Launcher.app」放入「应用程序」替换。首次迁移旧账户时，可能需要按系统提示完成一次钥匙串授权。

## 使用提示

- 这是预发布版本，部分旧整合包和设备适配仍在完善；目前不提供 Intel Mac 版本。
- Mac 唤醒或切换显示器后若偶发无法打开窗口，请待桌面恢复后重新打开。
- Mac 版尚未通过 Apple 公证，Windows 版暂未提供数字签名，首次运行可能出现系统安全提示。

遇到问题可通过启动器的「反馈」页面提交。
