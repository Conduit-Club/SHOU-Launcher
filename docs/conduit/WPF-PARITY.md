# WPF 样式与功能对等移植

本轮按 Windows 截图恢复信息架构和紧凑样式，使用既有 Avalonia12.1.5 控件。目标是完整取代WPF；当前仍是迁移候选，尚未达到删除旧入口的门禁。

## cleanroom 输入

参考归档：`UI-Reference-WPF-20261105.zip`，SHA-256 `695784a4ca98f6079763220f2971ce8b78fc3ee71fd187298b4f39c27cea6615`。已独立核对54类页面、132张正式截图；PNG之外的capture中间图不计数。仅提取截图与去除源码映射的可观察说明；包内XAML控件结构、源码覆盖映射及采集脚本未供实现agent使用，未读取旧WPF视图代码或样式模板。原有可移植业务接口继续复用。

参考图为Windows200%缩放，约976×635.5 DIP；新主窗基准976×636，标题栏48，启动账户区300，设置导航135，下载导航150。图中用户名、路径、版本数量、在线人数等不会写死。新版仍是一套跨平台Desktop/VM/Core，平台差异限于窗口和适配器。

## 分工与分支

本轮继承`features/macos-native-validation@3d9205cc`，其基线为本社团`origin/dev@b97b5656`。

- `features/wpf-parity`：主工作区、Core业务/接口、实例页、整合与验收。
- `features/wpf-parity-shell`：窗口/四项导航、共享主题、启动与工具、下载目录与资源页。
- `features/wpf-parity-settings`：设置/账户；第二批另负责NBT世界与服务器业务。

两worker按原任务的gpt-6.1-sol/max配置运行，不递归扩编；每人独立工作树、精确自有文件patch交付。只做本地阶段提交，未推送/合并PR/发布。旧分支及未提交输入保留；所有重任务仍受单锁和35GiB任务预算控制。

## 首批业务

- 启动/下载/设置/工具四项主导航和上下文返回；按场景改变左栏，保留真实认证、设备码/角色选择、离线档案、Java信任、代理及aria2密钥保护。
- 全局窗口宽高、全屏、初始内存与自定义说明真实接入启动计划；任意JVM参数等未支持项不假保存。
- Minecraft版本目录、Fabric目录、Modrinth资源检索/版本文件下载/收藏，使用现有代理/来源策略。资源下载有SHA-1/size校验；项目图标限制来源和大小，失败回退图块。
- 实例检索、改名、独立Java/内存、文件分类读取/导入、模组启停及实例ZIP导出；拒绝链接逃逸与覆盖同名文件。SHOU实例ZIP不是对MRpack/CurseForge格式的完整兼容声明。
- 修正实例列表重建时ListBox把新选中实例回写null的问题；修正高级来源选项的祖先DataContext空绑定警告。原Fabric业务契约测试保留，新下载流程另有交互测试。
- 活动进程停止/释放已移除UI同步上下文依赖，并用停止调度线程的真实Java子进程回归验证；Mac实窗关闭活动游戏的补验单列。

## 完全取代 WPF 的剩余门禁

需要补齐未支持加载器、内容安装/依赖、世界/服务器/数据包、皮肤/工具/主题与完整设置/弹窗行为；完成Windows原生运行、旧配置/实例/禁用Java导入、旧→新→旧数据往返、DPAPI/密钥兼容和双入口互斥。通过这些门禁后才切Windows默认入口和移除旧工程；此次没有删除WPF。

本机原始参考与证据位于`.shou-dev/references/wpf-20261105/`及`.shou-dev/reports/wpf-parity/`。外部API依据：[Modrinth搜索](https://docs.modrinth.com/api/operations/searchprojects/)、[项目版本](https://docs.modrinth.com/api/operations/getprojectversions/)、[Fabric Meta](https://github.com/FabricMC/fabric-meta/blob/master/README.md)。
