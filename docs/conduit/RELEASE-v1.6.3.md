# 潮涌核心社启动器 v1.6.3 · xb

本次预发布改善新实例、Java 和整合包的下载效率。

## 下载改进

- 内置下载的默认并发和可设置上限提高到 256。启动器会将旧配置中的 8 一次性迁移到 256。若设备或网络负担较重，可在设置中调低并发，新设置会保留。
- 对具有已知大小和哈希的大文件，支持最多 8 路分段下载。来源不支持分段时，自动回退到普通下载。
- 下载和复用旧文件时同步校验清单提供的哈希，减少重复读盘。取消后可从已保存的有效部分续传。

## 选择下载包

| 设备 | 下载文件 |
| --- | --- |
| Windows（Intel / AMD） | `SHOU-Launcher-win-x64-v1.6.3.zip` |
| Windows ARM64 | `SHOU-Launcher-win-arm64-v1.6.3.zip` |
| Apple Silicon Mac | `SHOU-Launcher-osx-arm64-v1.6.3.zip` |

Windows：退出启动器后解压，将新 EXE 放回原目录。无需另装 .NET。

macOS：退出启动器后，将解压的「SHOU Launcher.app」放入「应用程序」替换旧版。首次迁移旧账户时，可能需要按系统提示完成一次钥匙串授权。

## 使用提示

- 下载速度取决于来源、网络与设备，可在设置中按需调整并发和限速。
- 目前提供 Apple Silicon Mac 版本。Mac 包尚未通过 Apple 公证，Windows 包暂未提供数字签名，首次运行可能出现系统安全提示。
- 各下载包的 SHA-256 可在 GitHub 查看。

遇到问题可通过启动器的「反馈」页面提交。
