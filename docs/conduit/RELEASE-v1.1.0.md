# Conduit-Club v1.1.0（sxj）候选发行说明

本文记录当前版本目标 `v1.1.0`（代号 `sxj`）的功能范围和验证边界。正式包是否可下载，以[社团 Releases](https://github.com/Conduit-Club/PCL-CE-SHOU/releases)页面实际显示为准；本文不提前声明版本已经发布。v1.0.0（zst）的[首发说明](RELEASE-v1.0.0.md)保留作历史记录。

## 本版功能

- 修正 LittleSkin 与 MUA 的密码认证路径，识别 MUA 成员站接口并兼容旧 Union 档案；异常 HTTP/JSON 响应只显示友善错误，不泄露密码、令牌、响应正文或堆栈。
- 首次密码登录可导入服务端角色列表。账户按来源、服务器和 UUID 管理，避免把一个角色的令牌复制给其他角色；下拉账户列表保持紧凑，并支持缓存皮肤身份。
- 增加皮肤响应解析与角色皮肤选择支持。
- 增加社团更新日志索引、缓存和提醒设置。提醒与历史内容通过现有 `PanMsg` 原生弹层显示，不创建额外系统窗口；首页按钮与启动后提示路径保持一致。
- 首页右上角从 `smp.shoumc.com` 社团代理入口读取总在线人数，使用原始域名握手并遵守 SRV 端口；超时或不完整响应显示未知，不把三个入口的代理人数重复相加。
- 完成社团品牌与启动状态修复：`--versionType` 默认标识、旧 `PCLCE` 一次性迁移、中英文窗口/关于/退出文案、账户状态保护与启动服务器选择。

## 验证边界

- 当前 HEAD 离线全量测试：315 项，314 项通过、0 项失败、1 项跳过。跳过项为 `TestChaCha20Simple`，原因是测试平台不支持所需的 ChaCha20 硬件能力。
- 此前专项回归共 40 项，其中 39 项 Conduit 测试与 1 项 McPing 测试，全部通过；这不是认证测试数量。
- LittleSkin 与 MUA 的皮肤站邮箱密码登录路线已由用户实际确认可用。账户刷新、令牌刷新、角色切换和 Minecraft 联机尚未完成全量真实服务联调；Microsoft 授权也应以实际测试账户验证结果为准。
- 公开 `smp.shoumc.com` status-only smoke 曾返回 `online=2`、`max=114514`；该数据代表代理入口返回的状态口径，不等同于后台权威人数。
- 构建信息、源码提交和 SDK 配置应记录在 `BUILD-INFO.txt`；测试数字记录在本文，下载完整性使用 ZIP 旁的 `.sha256` 资产核验。
