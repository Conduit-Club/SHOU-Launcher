## 真实实例与资源链

从用户指定的既有 XPlus 26.2 目录只复制版本 JSON/JAR、89 个 Mod JAR、9 个资源 ZIP、4 个光影 ZIP，共 104 文件、185,397,755 字节。不复制原账户、配置或存档。原目录只读；游戏和设置操作均在独立副本完成。

- 组件准备、导出和游戏退出后，原目录与副本的这 104 个原文件 SHA-256 均保持一致。新配置、日志、服务器文件和地图缓存仅写入副本。
- SHOU ZIP 导回 102 个资源文件，MRpack 导回 102 个；逐文件哈希一致，均建立独立新实例。没有用已有目录覆盖导入。
- 原生“开始导出”实际生成 SHOU v2，独立核验 102 个文件的大小、SHA-1/SHA-512 和精确清单一致。
- 真实 Modrinth 查询→版本→安装计划→下载→安装：Fabric API、Fresh Animations、Complementary Reimagined 各安装成功；逐文件 SHA-512 一致，重复执行均新增 0。它们安装到独立资源验收实例，没有额外启动这些实例，也不把写盘成功当作游戏内效果通过。
- 原生表单新增“社团 SMP / smp.shoumc.com”，显式保存至副本 servers.dat；另一启动器会话读回该条目，连接按钮可用。游戏自身服务器列表也显示该记录及社团 MOTD。

## 本轮正版与 SMP 原生验收

本轮当前任务明确授权了 XPlus 26.2 → SMP。后续任务仍恢复默认禁止启动游戏的规则。

- 通过应用当前用户 DPAPI 路径读取本项目私有验收目录的两个微软账户。未扫描浏览器或其它账户存储，没有导出完整账户缓存。
- 选中账户启动前已过期；启动中实际刷新成功，到期时间前进并持久化。不是离线角色、只读缓存或生成计划代替认证。
- 使用真实 Windows Java 25、Fabric 0.19.3 启动 Minecraft 26.2。实际主菜单显示 269 个加载的 Mod 模块；目录内 Mod JAR 为 89 个，两种计数口径不同。
- 从首页 SMP 卡片快捷连接，实际进入“社团 SMP”，观察到地下区块、HUD、模组界面和世界渲染。只观察及切换客户端菜单/相机，没有移动角色、操作方块或发送聊天/服务器命令。
- 观察到 Java 命令行仅有安全引导入口，没有可见 token 参数。会话、账户标识和原始游戏日志不进入候选包、Git 或可分享报告。
- 正常关闭启动器后游戏仍存活；重开启动器识别到原游戏，凭据和账户状态仍正常。正常断开 SMP、回到主菜单、点击 Quit Game，原生进程退出码 **0**，无本轮游戏残留，启动按钮恢复可用。
- 世界 HUD 原始截图留在本机私有验收目录；可分享证据只复制不含账户身份的主菜单/服务器列表截图，并核对 SHA-256。私有路径和截图摘要在 `reports/r17-game-acceptance.json`。

游戏实测候选为 RC2 / `5d9b98ea`。其后 RC3 仅修改 Desktop 头像刷新代次和相关测试，Core、Java 引导与启动逻辑未变；没有为这项 UI 修正重复启动游戏。RC3 已原生打开、读取头像与账户并正常关闭。

## 首次失败及处理

1. 初次 Core 两项夹具失败：旧导出夹具缺少完整 Fabric/原版身份；新回滚夹具未建立预期故障目录。修正夹具后保留严格身份与回滚断言。另一次新取消/失败夹具期望 IOException，实际元数据服务按原设计抛 AggregateException，修正具体预期。
2. 初次 Desktop 三项仍断言“快捷进服禁用”，已更新为实际参数传递；新测试后续修正了模拟进程结束状态、Ready 状态名和启动后返回首页的视图断言。所有失败 TRX 保留，未删除断言绕过功能验证。
3. RC1 原生发现两项产品问题：匿名发行 API 限流，以及外部实例服务器页错误使用启动器数据根。已分别加入公开订阅备用通道及登记实例物理边界，在 RC2 真实复验通过。普通数据模式策略变化的两项旧断言同步改为验证“只允许当前登记目标”，未放宽链接/越界或运行中写保护。
4. 正版过期缓存触发头像 401 未自动重试，已在 RC3 修复并加入两项竞态回归。原生输入辅助曾遇到前台切换和 UIA SelectionPattern 方法调用错误，均在输入前停止并纠正，没有改全局快捷键或桌面设置。
