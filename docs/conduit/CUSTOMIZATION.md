## 基线与内容来源

初期社团定制基于 PCL-CE `dev` 的 `a42a7699948aebd1e2563df025274af255c1f559`。v1.2.0 最后纳入至 `f00b458e7bcf1368ea4e00148cf5db09bd1f5133`，之后转为独立维护，不再自动同步。历史迁移与来源声明见 [HISTORY.md](HISTORY.md)。

- [社团首页](https://conduit-club.github.io/)：主页文案与 QQ 群。
- [Velocity 文档](https://conduit-club.github.io/servers/velocity/)：认证服务、Minecraft 1.21.1 和三个公开入口，核对日期 2026-10-02。
- 用户提供的 `DESIGN (2).md`：嘉然配色采用奶油白 `#FDF9F3`、玫瑰粉 `#D17D8A`、强调色 `#904855`、可可棕 `#5D453E`，并添加对应深色版。原有蓝色选项继续可选。

## 已实现行为

- 品牌标识集中在 `ClubCatalog`：中文显示名为“潮涌核心社”，英文界面使用 “Conduit Club”。新安装的 Minecraft `--versionType` 默认值为“潮涌核心社”，Minecraft 接受 Unicode 版本类型；窗口标题、关于页和退出确认也使用对应的中英文资源。
- 旧用户的本地 `LaunchArgumentInfo=PCLCE` 只在首次配置初始化时迁移为“潮涌核心社”，并写入一次性迁移标记。空值以及任何其他自定义内容都会原样保留，后续更新不会覆盖用户选择。
- 这轮替换仅涉及社团可见品牌入口与默认值；程序集、打包资源、兼容路径、认证提供方、服务器协议、PCL-CE 原作者署名、许可证、赞助链接和上游历史说明继续保留。`LaunchArgumentTitle` 仍由用户自行设置，不会被品牌迁移强行填充。

- 主页展示社团说明、Wiki、入服指南与 QQ 群，移除原 CE 身份确认提示；新配置默认使用嘉然配色，已有配置首次升级一次性迁移为嘉然配色，之后可自由更改。
- 左上方按 MUA / LittleSkin / 微软分类并显示各自账户数量，来源下列出用户名（来源），点击后即时刷新下方登录区；列出账户及其来源（微软正版 / MUA Union / LittleSkin / 自定义 / 离线），按档案 ID 切换而不是按昵称混合身份。复用 CE 的加密账户存储和认证流程；切换会清除旧登录加载器状态并刷新左侧账户信息。
- 一键打开三种社团登录入口，不再要求先拥有微软档案才能创建第三方档案。第三方正版购买提示仍保留，但不会因此强制进入 demo 模式。
- 首页默认轮播社团官方截图（柔化、淡入淡出），可在个性化中关闭；窗口、任务栏与启动画面使用社团图标。顶部标题为“潮涌核心社启动器”与白底 SHOU 标识。
- 新配置的界面语言固定默认简体中文，保留用户主动选择其他语言或跟随系统的选项；首次启动不再要求点击免责声明确认，许可与协议说明保留在关于页。
- 启动器不再收集或上报遥测。设置里没有遥测开关；已保存的开启状态会在下次启动时重置。联机不再向原项目上报设备或账户信息，也不再读取其公告来开关联机、登录或中继。DoH 不再使用原项目解析地址。
- 服务器大按钮默认“只启动游戏”；选中后显示实际版本：SMP 1.21.1，Create / SHOU 1.21.11。
- 服务器选择持久化为独立配置，不写入游戏实例认证设置。社团模式使用当前受支持的账户；LabyMod 自身的正版限制仍保留。自定义账户可用于其他服务器或单机，离线账户不能用来进入社团服。
- 生存 `smp.shoumc.com`、创造 `create.shoumc.com`、校园 `shou.shoumc.com`，通过现有 Quick Play / 旧版 `--server` 支持自动连接。“只启动游戏”明确覆盖旧实例的自动进服设置；其他调用方不指定地址时仍沿用原行为。
- 更新页仅手动查询本社团 GitHub Releases，包括社团预发布，不再使用 CE 更新服务、MirrorChyan 或公告。下载按钮打开社团发行页面，不后台覆盖 EXE。整合包导出随附当前社团程序，不下载 CE 替换。
- 启动后默认后台检查社团更新日志总览页；只提示最新且尚未展示的日期记录，同日标题变化不会重复弹窗。提示与历史内容使用现有 `PanMsg` 原生弹层，不创建额外系统窗口；检查失败、链接不安全或启动/登录正忙时静默跳过并留待下次启动，可在“设置 → 个性化”关闭。
- 关于页先介绍社团，开发署名 Moeary / Codex；新增指导老师-ZRY 与空间博士-ZST，链接按用户提供的校方页面配置。社团贡献者只列两位，上游作者、赞助链接、鸣谢及许可证另行保留。

## 维护关注点

v1.3.0（dxy）新增首页纯净模式、自定义轮播、下载源优先级与 SHOU-MCMirror、外部 aria2 RPC、爱弥斯/高雅人士深浅配色。入口、使用方式与验证边界见 [RELEASE-v1.3.0.md](RELEASE-v1.3.0.md)。

新增逻辑集中在 `PCL.Core/Conduit`、`Pages/Conduit`、`Modules/Conduit` 和 `DianaPalette.cs`。必要接入仍修改了配置枚举、主题资源入口、首页、账户创建门槛、启动参数、微软 Client ID 选择、关于页以及更新模块。

更新管理器和更新页面已改为社团手动发行检查，属于与上游差异最大的部分。上游若调整这些文件，需按 AGENTS.md 逐项合并，不直接覆盖社团行为。账号缓存、实例认证优先级和主题索引是需要特别回归的接口。

当前版本目标为 `v1.3.0`（dxy），已发布包以社团 Releases 页面为准；`v1.0.0`（zst）的[首发说明](RELEASE-v1.0.0.md)保留作历史记录。发布新版本时同步调整 `ClubRelease.CurrentTag`、`ClubRelease.CurrentCodename` 与 `metadata.json` 中的版本。旧 `conduit-v2.15.1-club.*` 标签仅作为迁移基线，不得让更新检查把它们判定为高于正式首发版本。

## 验证边界

核心回归覆盖来源识别（含伪造域名）、同名不同来源账户切换与持久化、服务器选择与旧实例地址优先级、Release 草稿过滤与版本比较、深浅配色正文对比度。真实登录、令牌刷新和 Minecraft 联机仍需使用测试账户与已安装游戏进行人工验证；没有使用用户账户完成外部授权。

Microsoft Client ID 已配置到本地 `.env` 和仓库 Secret，构建时注入；API 审核已获准，实际登录仍需使用测试账户确认，详情见 `MICROSOFT-LOGIN.md`。
