# R49：旧格式安装、CF 手动更新与崩溃分析

2026-11-13；分支 `features/windows-parity`，沿用本社团 origin/dev 基线上的移植分支。无 PR 合并、正式发行或个人应用覆盖。本轮不启动 Minecraft。

## 行为

整合包取消移植时加入的归档/展开大小、文件数量、压缩率产品门槛，使用 ZIP64 读取与流式 CRC/SHA-1/SHA-512/复制。真实磁盘空间检查保留；空间不足、归档改变、CRC/哈希错误、路径越界、重复目标或取消会进入原事务失败/回滚处理，不发布半成品实例。开发任务的 35 GiB/系统 20 GiB 留量门禁不属于产品限制，保持原样。

HMCL 的 minecraft 层、MCBBS addons/overrides、MultiMC components/instance.cfg/patches/.minecraft 与普通 versions/id/id.json 压缩实例接入真实暂存、注册和重启读取。任意合法的游戏载荷均保留，不以目录或扩展名猜测是否有用。内存、附加 JVM/游戏参数、随包客户端/依赖库和已覆盖加载器元数据保留；独立缓存命名空间避免改写共享版本。移植版仅允许少数 JVM/游戏参数的白名单已撤销，恢复旧版自定义参数；导入本身不执行启动命令。

CF 缺少第三方 downloadUrl 的正式新版继续出现在可更新列表。预检收集根文件与 required 依赖的官方项目/版本/大小/SHA-1，界面提供官网与选择文件，校验后接回已有备份/替换链。错误文件不会被采纳，离页回调不会继续更新；重查使旧令牌失效。资源包和光影仍按旧版只更新所选归档，不顺带安装模组。没有猜测 CDN 或绕过作者下载方式。

崩溃分析复用本仓库原版 CrashRuleCatalog、CrashEvidenceExtractor、CrashStackAnalyzer 及原因文本；Core 编译可移植业务文件，不引用 WPF UI。原顺序为 Fatal、Primary、堆栈、Secondary；本地 Mod 索引和日志分类/首尾取样仍按旧业务规则。百宝箱提供日志/ZIP/GZip/BZip2、当前实例分析及完整脱敏日志 ZIP 导出。非正常退出分析本次会话输出，按启动时间排除陈旧实例日志，通知提供直达按钮。用户此前取消的发行更新检查提示没有恢复。
