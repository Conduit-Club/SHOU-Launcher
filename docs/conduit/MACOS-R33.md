## 完成范围

- 完整文件统计在 Core 按任务身份增量维护，覆盖全部本次启动的文件任务；UI 的最近 250 行不决定总数/字节/连接。重复完成替换旧贡献，重试回退进度、未知大小完成时补实测大小，缓存复用单独计数。
- `DownloadTotals` 是本次启动汇总；`DownloadActivity` 是当前/最近一组；`DownloadHistory` 最多 50 组会话内操作记录。当前进度取当前组，旧失败记录仍可见而不拖低新成功组。累计就绪包含续传/缓存，不等于网络流量；解析会继续发现文件，未知工作和后处理保留不定进度。
- HTTP 传输刷出最后字节的进度回调；重复完成不重复累计速度，显示超过 1.5 秒无新样本时归零。CF/FTB 固定资源通道保留 cache 标识。内置每文件按一个活动传输计，Aria2 采用报告的分段连接数；校验/结束后归零。
- UI 后台快照通知合并为一次读取最新快照；完整统计在 Core 保留，不依赖处理每条 UI 通知。未知大小文件完成/取消后不再无止境转圈。
- 设置来源内容语义相同时保留原行与选择，保存不会因为无关设置重载列表而跳位；有实质变更的放弃草稿仍读回旧值。中文限速说明按实际内置/外部后端策略修正。
- Aria2 保持用户要求的本机端口连接优先，没有加入发现、安装、进程启停或 Windows 包管理器依赖。
