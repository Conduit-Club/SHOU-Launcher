# Windows R14：工具接入与账户表单收敛

2026-11-07。产品提交 `6b65c639`（主要实现）、`879489e7`（迟到进度/关闭清理与提示收敛）。沿用 `features/windows-parity` 迁移分支；没有合并 main/dev、推送、切换默认入口或正式发布。原工作区已有修改保持原状。

本轮没有启动 Minecraft，没有执行下载的安装器，没有读取真实旧账户缓存，也没有填写真实登录凭据。现有 Microsoft 标准设备授权及 MUA/LittleSkin 密码认证服务保留，真实登录不计为本轮通过。

日志工具只选超过一天的直接 `logs/*.log`、`*.log.gz` 和 `crash-reports/crash-*.txt`，移动前核对大小/SHA-256，写收据，放入实例内 `.shou-trash/game-logs`，恢复拒绝同名覆盖。保留世界、模组、截图、配置及近期日志。它是可恢复整理，不宣称释放磁盘空间；启动器缓存清理仍待补。

今日人品按安装种子与日期稳定；计数读取实例已有持久记录。Windows `.lnk` 指向本启动器并带当前数据目录，未执行该链接；macOS 使用平台适配层生成 Finder `.app` 入口，待实机验收。

自定义下载限制 512 MiB，拒绝嵌入账户密码的地址、HTTPS 降级、过多跳转、路径别名与覆盖。新文件完整收取后才原子发布。下载使用独立匿名 HTTP 连接，不转发 Microsoft/CF API 凭据；不关闭 TLS 验证。成就文字只在本机渲染，不上传、不捆绑字体；目前内置四种物品，并可选择 PNG 图标，完整旧物品 ID 库尚未恢复。

共享业务继续在 Core；窗口/文件选择器使用共享 Avalonia，Windows COM 和 macOS 快捷方式放在平台层。只参考可移植的旧 UUID/哈希与快捷方式业务，不读取 WPF 视图、样式或控件结构作为实现输入，不使用旧 WPF fallback。
