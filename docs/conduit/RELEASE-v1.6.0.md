# 潮涌核心社启动器 v1.6.0 · xb

新版双端启动器预发布，支持 Windows 和 Apple Silicon Mac。

## 本次更新

- 延续旧版界面与使用习惯，更新首页、账户、下载、实例管理和设置页面。
- 支持整合包拖入安装、导入与导出；补齐模组、资源包和光影包的自动检查更新、可更新筛选与直接更新。
- 改善 macOS 游戏启动和账户保存体验，普通更新后可继续读取已保存的账户。
- 支持连接已启动的 aria2 下载服务；服务不可用时自动使用内置下载。
- 设置修改即时保存，提供简体中文、繁體中文和 English。

## 选择下载包

| 设备 | 下载文件 |
| --- | --- |
| 常规 Windows 电脑（Intel / AMD） | `SHOU-Launcher-win-x64-v1.6.zip` |
| Windows ARM64 设备 | `SHOU-Launcher-win-arm64-v1.6.zip` |
| Mac M 系列芯片 | `SHOU-Launcher-osx-arm64-v1.6.zip` |

Windows：解压后运行 EXE，无需另装 .NET。更新时退出启动器，将新程序放回原目录，可继续使用原实例和同一 Windows 用户保存的账户。

macOS：解压后将「SHOU Launcher.app」放入「应用程序」，替换前先退出旧版。首次迁移旧账户时，可能需要按系统提示完成一次钥匙串授权。

## 使用提示

- 这是预发布版本，部分旧整合包和设备适配仍在完善；目前不提供 Intel Mac 版本。
- Mac 唤醒或切换显示器后若偶发无法打开窗口，请待桌面恢复后重新打开。
- Mac 版尚未通过 Apple 公证，Windows 版暂未提供数字签名，首次运行可能出现系统安全提示。

遇到问题可通过启动器的「反馈」页面提交。
