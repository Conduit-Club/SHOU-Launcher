# Mac R36：本地整合包手动补文件恢复

本轮继续 `features/windows-parity` 的 R29-P01：让本地 CurseForge ZIP 与软件内下载共用手动补文件行。官网文件需通过原归档、项目/文件身份、大小和哈希核实，逐项补充后重新预检；所有必需项就绪后仍需用户确认导入。

## 实现

- 本地面板提供官网、选择已下载文件和重新预检；文件名、大小、官方文件 ID 及换行操作布局共用同一模板，搜索页继续只保留搜索旁的本地入口。
- 自动重新预检保留实例名称、准备游戏选项及同一归档的可选文件选择。预检失败或取消后禁止安装，保留可重试的剩余项；显式重检成功后恢复。
- 切换归档、界面销毁、取消后迟到响应和原包哈希变化均有保护；旧文件选择回调不能补到另一个整合包。在线安装仍在全部补齐后继续后台任务，本地安装仍需显式确认。
- 新增提示只维护简体中文、繁體中文、English，复用底层既有校验与允许来源策略；未改 Windows/macOS 运行库或游戏参数。
