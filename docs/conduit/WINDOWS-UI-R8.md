## 游戏所有权与保护边界

共享 Core 维护会话与实例保护；Windows 窗口观察位于平台层。公开启动命令行继续只有受信 Bootstrap/JVM 参数，实际游戏参数/凭据继续使用一次性私有 stdin，没有明文脚本或参数文件。

会话身份只记录 PID 与操作系统创建时间，按实例物理目录散列归属。登记在私有输入交接前完成；失败则停止新建的受控子进程。重开后按精确创建时间拒绝 PID 复用，只用于显示和保护实例，**磁盘记录不授权按 PID 终止进程**。损坏/无法核验的记录阻止该实例修改；历史记录保留，不删除用户数据。

Java 受信引导在游戏入口前建立独立日志，按行处理跨块敏感值，超长行省略，单文件上限 8 MiB；UI 退出后游戏可继续写日志。主线程进入方式及 macOS -XstartOnFirstThread 保持。停止指定的当前受控进程与关闭 UI 分离；重开后脱离 UI 的游戏目前使用游戏内 Quit，受验证的停止入口仍待完善。
