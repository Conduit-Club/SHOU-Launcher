# R41：实例资源列表贴近旧 WPF（2026-11-12）

本轮以用户提供的模组、资源包、光影三张 WPF 实窗图为直接视觉参考，对照 `PageInstanceCompResource` 与 `MyLocalCompItem`，改进现有 Core/Avalonia。旧 WPF 源码保持不变；当前功能分支继续为 `features/windows-parity`。

## 界面与交互

- 三页恢复共同结构：带搜索图标的搜索卡片、工具栏卡片、带筛选和右侧排序的列表卡片。工具顺序为打开文件夹、从文件安装、下载新资源、全选、导出信息；模组页另有模组关系。
- 列表实际行高 44 像素，图标 34×34；名称与版本在同一行，下一行是标签、文件名与描述。长文字省略并保留详情，不再每项占用四行。更新标记紧跟版本。
- 模组行提供详情、定位文件、启停和回收图标；鼠标悬停、键盘焦点和选中状态下显示。资源包/光影保留可用的详情与定位，不放置尚未实现的启停/回收空按钮。
- 行点击和空格支持选择；按钮操作不会再次切换选择。多选工具条放到右下浮层，选中时不把列表整体向下推；导出优先采用实际选中项，未选时导出筛选结果。资源包和光影的全选与导出一并可用。
- 按旧 WPF 的规则显示有意义的筛选：全部/当前筛选保留，其余仅在有对应文件时显示；全部启用时不重复显示启用筛选。排序与筛选在同一卡片头部，手动重查、重新读取和回收入口保留，自动检查状态移至列表尾部。
- 共享文件列表也适用于投影目录，截图和存档继续使用各自专用视图。新静态文案及资源包/光影分类标签维护简体中文、繁體中文、English，搜索仍保留原始分类标识。

## 本地与在线展示信息

- 资源包和光影 ZIP 可读取本地 `pack.png`/`icon.png`，资源包描述支持普通文本与 JSON 文本组件。元数据仅用于显示，不解包、不执行、不改变导入规则；坏描述不遮掉有效图标，坏 ZIP 仍保留文件行和明确错误。
- 新的只读资源信息服务按文件 SHA-1/大小核实 Modrinth 版本，再核实项目 ID 与资源类型，补名称、当前版本、描述、分类与在线图标。已核实结果按内容身份缓存六小时，读取不会延长原检查时间。
- 本地模组/资源包展示和关系读取兼容 BOM、注释、尾逗号及说明字符串的原始换行；说明压成单行，标识与归档路径校验保留，不用于远端身份或安装清单。真实 BetterGrassify 归档不再因换行被误报损坏，坏结构仍提示错误，原 JAR 不改写。
- 每项有超时、并发上限与取消；未识别/网络失败继续保留本机信息。离页、换实例或重新读取丢弃迟到结果，写入等待已取消的读取释放句柄。
- 这不是资源包/光影的更新安装实现：未生成更新令牌、未猜测新版本、未显示虚假的“可更新”计数。CF 专有身份等无法核实的资源继续用本地展示信息。
