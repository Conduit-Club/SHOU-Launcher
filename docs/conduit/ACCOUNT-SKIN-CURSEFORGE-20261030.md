# 首页账户、3D 预览与 CurseForge

对应社团 [Issue #11](https://github.com/Conduit-Club/SHOU-Launcher/issues/11)。开发基线为 `origin/dev` 的 `09001533`，不改变当前正式版本号。

## 账户入口

- 两行两列：第一行微软正版、LittleSkin，第二行 MUA、离线（盗版）。每个入口显示已有角色数，离线入口支持筛选、切换和直接添加本地角色。
- 移除离线启动时的购买/验证提示弹窗。输入校验及实例、服务器本身的认证要求继续生效。

## 3D 预览

- 账户头像下方的皮肤菜单新增“允许 3D 皮肤展示”和“3D 预览皮肤与披风”。开关默认关闭，保存在本机；开启后可预览当前微软正版账户。
- 弹窗读取 Mojang 公共 session profile 中当前装备的皮肤、模型类型及披风，不传输账户令牌。打开时固定账户快照，关闭时取消请求，刷新失败时明确标记旧预览。
- WPF 原生模型支持经典/纤细手臂、64×32 旧皮肤、64×64 及整数倍高清皮肤、皮肤外层和披风。拖动或方向键旋转，滚轮或 `+` / `-` 缩放，`Home` / 复位按钮恢复视角，`Esc` 关闭。外层和披风可单独隐藏。
- 没有自定义皮肤时明确标记内置默认模型；披风请求失败不会被表述成“未装备披风”。此功能展示常规皮肤和披风，不渲染鞘翅、第三方模型或模组特效。

## 下载

- 构建脚本兼容本机现有 `CURSEFORGE_API` 名称，仍推荐 `PCL_CURSEFORGE_API_KEY`。别名、引号及进程环境优先级见 [BUILD.md](BUILD.md)。`.env` 不纳入版本控制，Key 不写入日志或下载 URL。
- 默认优先 CurseForge / Modrinth 官方 API 和文件源，失败后回退 MCIM；GET、只读批量 POST 和文件列表共用来源顺序。保存的自定义顺序、禁用项及旧版镜像优先设置继续生效。
- 认证头仅发往官方 HTTPS API / 文件 CDN 主机。CurseForge 官方文件使用内置下载器，避免 aria2 在一个多来源任务中把同一认证头发送给镜像；其他下载继续使用已选择的下载后端。
- 官方 CDN 的认证要求见 [CurseForge 公告](https://blog.curseforge.com/introducing-api-key-authentication-for-curseforge-file-downloads/)，API 协议见 [官方文档](https://docs.curseforge.com/rest-api/)。Key 不解除作者分发限制，也不保证每个版本的镜像都可用。
