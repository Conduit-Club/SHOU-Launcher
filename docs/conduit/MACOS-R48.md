## 对照与实现

对照本仓库旧 `PageDownloadCompFavorites.xaml.cs`、`ModComp.CompFavorites.FavData`、`CustomEvent.cs`、`PageLaunchRight.xaml.cs` 和 `FormMain` 的可见行为与协议，独立实现可移植部分，未检查或同步原上游。

- 自定义主页：Grid 行列/跨格、尺寸/边距/对齐/常用颜色/文字属性、可折叠卡片；支持旧中文/英文网页、复制、刷新、提示、对话框、常用切页事件及 Events 集合。本地文件原子替换后防抖刷新，离开解除监视、返回读取最新文件。纯文本与既有图片边界保持；不调用运行时 XAML/CLR。
- 收藏：备注按组保存，编辑保存/取消；按类型折叠、中文名/备注/描述/标签搜索与基础拼写容错。复制/移动所选至其他组时保留目标既有备注。旧版删除组会确认并移除该组内容，R47 自动移动至另一组的行为已纠正；其他组成员不变，保留上次文件备份。
- 旧收藏导入：支持 Favs/Notes 数组、原分享 ID 数组、含 Game.CompFavorites 的 JSON 导出。只读取收藏字段，不导入账户或其他设置；按旧组身份去重，失败 ID 和备注持久保留并可重试。保存 v3，兼容原数组/v1/v2/v3；未知/损坏文件原样保留，旧客户端不应覆写不认识的 v3。
- 批量下载：并行查询所选项目，先求共同加载器/游戏版本，用户选保存目录，展示最新对应文件计划（可能含测试版），沿用已有传输后端/任务通知/取消与分组重试。正确文件复用，同名不同内容不覆盖；各项失败继续其他项，失败组重试会复用完成文件；下载后再次校验大小/SHA-1，临时文件不作为成功文件出现。换选择/换组/离页使旧方案和迟到的目录选择失效。只保存资源文件，不安装到实例。

新增界面静态文案提供简中、繁中、English；未把全界面三语与 VoiceOver 矩阵记作通过。模糊匹配是独立近似实现，不声称与旧 WPF 搜索权重完全相同。
