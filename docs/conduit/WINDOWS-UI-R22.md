## 实现与兼容边界

共享 Avalonia 存档列表和数据包页接入现有下载页：明确保留当前实例，数据包保留明确选择的存档；不会修改首页账户/实例选择，不会自动安装。项目详情继续走 R19 的兼容、冲突预检及独立确认。切换实例、同 ID 目录重绑、失效存档和迟到读取均不能把旧目标重新套上，目标变化使旧预检失效。

数据包页“从剪贴板导入”只读取原生文件项，接受单个本机 ZIP。多文件、URL、普通文本及文件选择后切换目标均被拒绝。沿用已有本地 ZIP 读取预算、内容/路径检查、同名拒绝和原子发布，不写 level.dat；没有自动读取文本、执行内容或启动游戏。真实跨应用文件剪贴板另列待验。

回收使用新 Core 接口 `IWorldDatapackTrashService`。新增读取、回收和恢复沿用页内操作状态，不增加底部进度条。游戏必须停止，目标必须是当前明确选择、符合既有隔离目录边界的实例；沿用 `WorldStore` 的运行会话/路径/链接守卫。仅写入已验证 Java 1.21.1（DataVersion 3955）且 DataPacks 列表完整的世界，数据包格式 48；不为填满 UI 放宽未验证格式。

先选择 1–16 个数据包，再确认回收。ZIP 与目录移入该存档的 `.shou-trash/datapacks/<id>/payload`，核对完整内容哈希；同时移除 level.dat 的对应 Enabled/Disabled 引用和世界安装清单中的对应文件记录。原 NBT/JSON 未知字段保留，level.dat 和清单写前备份逐字节保持。未提供永久删除；最多 256 条回收记录，达到上限会在移动前拒绝，须先备份并人工整理，启动器不自动清除历史资料。

收据保存本次前后元数据和哈希，重建服务/界面后仍可读取、恢复。恢复保留原 ZIP/目录、原启停顺序和原安装清单；不会覆盖同名或 Unicode/大小写等价路径。**恢复要求当前 level.dat 与安装清单仍等于本次回收后的状态**；若已进入游戏、编辑世界或安装其它资源导致其变化，拒绝自动恢复并保留回收文件，不能用旧备份覆盖新状态。这是本轮有意保守的边界，并非任意后续修改都能自动合并。

正常取消/写入失败会逆序回滚已移动文件及已提交元数据，保留原内容，不留本轮 `.tmp`。若外部进程同时改写目标导致安全回滚无法完成，则保留收据、备份与载荷，明确报错；不删除外来文件，不把“保留恢复材料”算成断电自动恢复已经完成。回收备份属于本机存档资料，不进入 Git、候选或公开证据包。

## Mac 侧原生补验清单

1. 使用独立的已验证 1.21.1 测试存档副本，不启动游戏；在存档列表和数据包页分别打开下载页，核对明确实例/存档、自动读取、返回及改变目标后的预检失效。
2. Finder 复制单个本地 ZIP，在数据包页粘贴；核对多文件/文字拒绝、同名冲突、取消以及异步读取期间切换目标不误写。原存档 level.dat 哈希应保持。
3. 选择 ZIP 与目录数据包，先取消回收确认，再真正回收；核对原始内容、启停引用和清单备份。正常关闭重开启动器，读取回收记录并恢复，原文件与元数据哈希应恢复一致。
4. 在独立副本中制造同名目标、回收载荷变更或后续存档修改，核对拒绝覆盖及恢复材料保留；选择器、最小窗口、键盘和无障碍另验。不把交叉构建写成 Mac 已运行。
