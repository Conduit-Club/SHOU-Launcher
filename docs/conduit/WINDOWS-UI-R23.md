## 行为与兼容范围

存档列表接上“导入本地世界 ZIP”和文件剪贴板入口，明确保留当前实例，允许编辑新的存档文件夹名。选文件不会写盘，也不会新建游戏实例；必须先检查，再独立确认导入。多文件、普通文本、URL、选择器返回时已改变的实例/目录均拒绝。名称变化会释放旧预检，实例或外部选中状态改变会丢弃迟到结果；Esc 及取消可关闭草稿或取消当前检查/导入。

Core 通过 `ILocalWorldImportService` 复用 R19 的世界计划、数据包检查与新目录原子发布。通过经官方大小/SHA-1 核实的基础客户端 version.json 获取实际世界版本/数据包格式；首次缺少缓存时可能下载该校验文件，不调用游戏入口。原 ZIP 只读，预检和确认都核对物理文件身份及完整 SHA-256；目标实例、版本、saves 边界、运行会话、同名/大小写/Unicode 冲突继续受保护。

支持 ZIP 根目录或唯一包装目录。沿用 ZIP 256 MiB、展开 512 MiB、单文件 128 MiB、5000 条目等预算、路径/链接/CRC 及敏感文件拒绝；不升级或降级世界。内带数据包必须与目标格式相符，缺失或不可核实的内建/模组依赖会阻止导入。仅本地入口忽略 `.DS_Store` 及 `__MACOSX/` 下 `._` AppleDouble 伴生文件；忽略的内容不写入目标，整个 ZIP 仍保持原样。其它隐藏文件和未知管理资料不一概跳过。

先在所选实例下的独立暂存目录完整解包、校验，再发布为新存档；旧世界和原 ZIP 不覆盖。旧 session.lock 不导入。来源收据仅存文件名、SHA-256、游戏版本及 local-world 类别，不存本机源路径或伪造在线项目 ID。NBT 和 region 等载荷逐文件保留，来源 ZIP SHA-256 不变。没有读取账号、操作旧 WPF 数据或启动 Minecraft。

正常取消与后段解包失败清理本次暂存，不留半成品；目标竞争时保留外来文件。原子发布已经完成后才到达的取消按完成反馈并刷新列表，不删除完整存档或宣称已经回滚。程序突然退出/断电后的自动恢复仍未实现，不把正常取消回滚当作该门禁完成。

界面沿用共享字体、按钮和输入框样式；检查/导入采用页内 LoadingGlyph、状态及取消，不新增底部进度条。世界列表刷新也采用页内状态。修复全局取消过程中同步完成的任务先释放 CTS、随后又读取 Token 所造成的 ObjectDisposedException：取消前先捕获 Token，已有认证取消清理继续使用该 Token。
