## 数据、安全和兼容边界

- 新行为为可选配置，旧偏好仍保留；界面偏好写前 `.bak`、原子替换并合并未知字段。设置导入先成为草稿，显式保存后应用。
- 设置导出不包含账户缓存、凭据、Microsoft Client ID 覆盖、代理/aria2 密钥引用和 Java 证书选用收据；导入不会注入这些引用。原生只用自建隔离数据，无真实账户。
- 日志导出只读本启动器日志目录，最多 100 个文本日志、每个最多尾部 1 MiB，并在 ZIP 中说明截断；脱敏 token/密码/Cookie/URL 凭据与查询、用户主目录。没有把日志 ZIP 或设置导出放入公开证据。
- 历史日志回收限超过七天的受支持日志；保留当前/游戏日志、未知文件，预览后检查大小/哈希和路径，保存恢复收据。原生没有点击回收，实际文件操作由 Core 受控目录验证。
- 公开发行、反馈和远程纯文本主页使用独立匿名 HTTP 客户端，保留代理设置，凭据不跨客户端或重定向泄漏；只允许 HTTPS 及限定的发布 CDN 跳转。
- 新版包需要 `SHOU-Launcher-<rid>-release.json`，格式 `SHOU-Desktop-Release-v1`，明确产品、runtime、源码、Avalonia、自包含与包名称/大小/SHA-256，并匹配 GitHub 工件摘要。发布入口现在生成此清单。缺少/不匹配清单的旧 WPF EXE/ZIP 只供阅读历史说明，不提供为新版更新包。
- 发行清单不是签名或自动更新器；替换、回退、版本比较和两端签名/公证仍未完成。当前本地候选未上传到发行页。
- 自定义主页目前显示 TXT/Markdown 纯文本，不运行旧 XAML、HTML 或脚本。自选图片/音频保留原文件；失效图片回退内置图。
- 设置页离开和关闭会取消/等待本页任务；导出使用独立暂存，完成才发布，取消不选用半成品。外部网络限流显示可重试提示，切页清除本页状态，保存后清除导入草稿提示。
