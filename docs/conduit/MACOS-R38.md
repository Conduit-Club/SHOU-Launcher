# R38：整合包可选文件选择与恢复

本轮补齐 R37 审计发现的 CurseForge 可选文件缺口。旧 WPF v1.5.0（`8746ad26`）在 `ModModpack.cs` 中收集 `required=false` 并询问是否下载；移植版此前只解析必需项。本轮恢复用户选择能力，使用集中列表代替逐个弹窗。继续在既有 `features/windows-parity` 分支开发，未改动 `dev`、`main` 或正式发布。

## 行为与实现

- 本地 CF ZIP 显示默认展开的客户端可选文件列表，默认均不勾选；选择后自动重新核实，再执行导入。必需项不受选择影响。名称和“同时下载并安装游戏文件”选项在重检、补文件后保留。
- 软件内下载任务遇到 CF/MRpack 可选项时停在“等待选择可选文件”，点击“按所选项目继续安装”才继续；可以明确选择全部跳过。不会自动全装，也不会无提示略过。MRpack 本地既有选择能力保持。
- CF 名称由官方文件元数据提供；未选项的元数据不可用时显示项目/文件 ID 和提示，不阻塞必需项。选中后仍须通过原有官方解析、来源、大小和哈希核验。
- 预检计划以归档 SHA-256 和所选键集合共同标识。未知键、重复键、将必需项伪装成可选项均拒绝；切换选择不能误用另一份缓存计划。归档内容变化清除旧选择认可，重新确认后再继续。
- 选中不允许第三方下载的 CF 文件时，沿用官网获取、选择已下载文件、官方身份/大小/哈希核验与重新预检流程。取消选择会撤销对应补文件入口；迟到的选择器回调、取消后回调、页面销毁均不能偷偷导入。后台取消/重试保留同包选择，但重新要求确认。
- 安装清单将所选 CF 可选项记为 `Client=optional`；CF 再导出保留 `required=false`，不把可选项转成必需项。
- 本次选择只控制 manifest 中的**可选下载**。CF overrides 仍按 R37 完整复制；包作者已经放进 overrides 的同名内容不会因取消远程下载而被删除。未重新加入目录或扩展名白名单。
- 新增提示维护简体中文、繁體中文和 English；不代表历史词条已全部译齐。

涉及 Core 的 `LocalPackContracts`、`CurseForgePackSelection`、解析器、预检/手动补文件/暂存及导出，以及 Desktop 的本地安装、后台任务、共享选择模板和三语资源。没有改变 Windows 的运行库、Java 或游戏启动策略。

## Mac 原生验收

使用 CUA 操作最终候选的隔离 QA 应用和原生文件选择器。样本为合成 CF manifest，引用 BetterTabs 与 RTG 的真实官方项目/文件身份；元数据在线获取，内容使用先前验证缓存。手动补充 RTG 由真实 Downloads 文件选择器完成。此证据不等同于重新联网下载一个完整整合包或网络性能测试。

| 流程 | 观察与落盘结果 |
|---|---|
| 不勾选可选项 | `R38 None` 仅含配置，1 文件 |
| 仅选 BetterTabs | 自动重检并导入 `R38 BetterTabs`，配置 + BetterTabs，2 文件 |
| 仅选 RTG，需手动补充 | 先停在缺文件状态，不创建第三实例；选错 ZIP 明确拒绝；选择正确 RTG 后名称/勾选保留，显式导入 `R38 Manual RTG`，配置 + RTG，2 文件 |

三个实例的实际文件集合与安装清单完全一致，配置原字节 SHA-256、全部文件大小/SHA-1/SHA-512、官方文件身份和可选标志均核实。未选的另一个模组不存在。原生滚动和文件选择器可用；Command–Q 正常退出，退出结果 `normal_close`、原生窗口句柄为真，QA 进程消失。

本轮未启动 Minecraft，三个实例都未准备游戏本体；隔离账户为空、游戏会话不存在。没有操作个人应用或个人实例，`.env` 元数据和无关计划文件哈希不变。

本地证据包含 `native-manual-pending.ax.txt`、`native-wrong-file.ax.txt`、`native-manual-ready.ax.txt`、`native-manual-installed.ax.txt`、选择截图、`native-subsets-final.json`、`native-result-1.json` 和 `preservation-and-exit.json`。空间门禁保持 35 GiB/预留 20 GiB；只回收已通过运行时间范围内的合成 GUID 夹具，完整日志/TRX/候选保留。
