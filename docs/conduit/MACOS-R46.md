## WPF 对照与范围

继续追 `PageInstanceCompResource.xaml.cs` 的 `EnterFolder`、`GoBackToParentFolder`、`InstallCompFiles`，并核对 `ModLocalComp.cs` 的实际枚举。旧版共享页面虽然有通用目录代码，底层只有投影分支构造文件夹项，普通模组/资源包/光影主要读取顶层文件；旧 Forge 的 MC 版本子目录另有特例。本轮据此优先恢复投影，不将其它三类“不递归”直接视为缺陷，也没有擅自扩大自动更新范围。

| 本轮内容 | 结果 |
| --- | --- |
| 目录浏览 | 投影目录置顶、当前路径、双击/Enter/行内进入、上一级/Backspace、空目录提示、打开当前文件夹 |
| 当前目录安装 | 原生选择器与拖入服务捕获目标目录；子目录消失即失败，禁止悄悄安装到根目录 |

| 导航并发 | 离页/换实例重置路径，丢弃迟到读取和过期选择器结果，旧行不能操作新页面 |

文件夹目前作为导航项，排除在文件批量选择和回收之外；文件夹树回收/恢复、目录级导入、投影材质/尺寸预览与游戏内兼容仍未实现。不把文件复制成功记作投影格式加载或游戏可用。新提示维护简体中文、繁體中文与 English。

新增可选接口 `IInstanceContentBrowserService`，目录相对于 `schematics`，检查路径越界和各级链接；现有接口与其它资源列表、更新检查范围不变。投影子目录文件复用 `ModFileManagement` 的哈希、回滚、清单和目标冲突保护；目录被替换成链接时拒绝恢复，移除链接后收据和原文件仍可恢复。接口细节见 [CONTRACTS](../../CONTRACTS.md)。
