# v1.5.0 · wyc

潮涌核心社启动器的独立维护版本，基于 PR #12 与 `dev → main` 稳定分支整合。版本代码为 `529`，正式包使用 Release 配置、Windows x64 自包含单文件程序，无需额外安装 .NET。

## 本次变化

- 首页账户来源改为两行两列：上方微软正版、LittleSkin，下方 MUA、盗版登录；支持各来源的账户计数、筛选和切换。
- 去掉离线启动时的购买提示弹窗，保留账户数据校验与正版认证流程。
- 皮肤菜单新增默认关闭的“允许 3D 皮肤展示”选项，可预览当前微软正版账户的皮肤与披风；支持经典 / 纤细 / 旧版 / 高清皮肤、外层开关、旋转、缩放、刷新和 Esc 关闭。
- CurseForge 项目 API Key 通过仓库 Secret 注入客户端；Mod 查询、批量查询与下载统一采用官方优先、镜像回退，并尊重自定义下载源的排序和禁用设置。
- 修复跨架构构建残留与环境变量变化后编译缓存复用问题；编译后验证微软 Client ID、CurseForge Key 和源码 SHA 确实进入产物，日志仅记录布尔结果。
- 旧本地产物已移至仓库外的可恢复归档目录，不随发行包分发。

## 验证与已知限制

- PR #12 已通过 x64 / ARM64 编译，以及 WPF 8 项、Java 19 项、社团回归 117 项、核心离线 375 项云端测试。专项与核心测试存在重叠，不相加作为独立用例数。
- 账户与 3D 预览已完成界面交互验证；公共 Mojang 皮肤 / 披风、CurseForge API 与官方 CDN 下载及 SHA-1 校验已通过。正式版本的构建与测试结果以本次 Actions 及发行记录为准。
- CurseForge Key 会随客户端分发，可从程序中提取；GitHub Secrets 保护仓库及构建输入，不提供客户端运行时保密。未注入 OAuth Client Secret、个人 GitHub Token 或服务器私钥。
- 真实 Microsoft 授权、完整 Minecraft 安装与启动、两端联机、物理高 DPI 与 ARM64 真机仍需实测；现有历史编译警告保留。
- 程序未作 Authenticode 签名。正式包为 `SHOU-Launcher-win-x64-v1.5.0.zip`，附 SHA-256 校验文件；源码提交、SDK、架构、配置及凭据注入验证结果见包内 `BUILD-INFO.txt`。
