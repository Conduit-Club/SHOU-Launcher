## 旧新差距与本轮结果

参考 `Plain Craft Launcher 2/Pages/PageInstance/PageInstanceCompResource.xaml.cs` 的 `BuildLocalCompItemBtnHandler`、`Info_Click`、收藏和分享处理。旧代码作为行为参考，跨平台实现沿用现有 Core 事务和桌面页面。

| WPF 行为 | 本轮处理 |
| --- | --- |
| 非模组文件提供信息、定位、删除；只有模组额外提供启停 | 资源包、光影和投影补行内删除与批量删除；采用实例内可恢复回收，不添加非模组启停开关 |
| 已识别资源信息可进入下载详情 | 本地详情加“查看下载详情”，复用版本、下载、收藏；保留精确实例、目录、游戏版本和返回原页搜索的上下文。比旧版直接跳转多一步 |
| 收藏分组、批量收藏、特定分享码协议 | 尚未复刻；已有单项目收藏可经详情访问，复制链接不等于旧分享码 |
| 文件夹双击进入 | 目录层级仍待补，当前回收范围为现有顶层文件列表 |

## 实现

- 增量 `IInstanceContentTrashService` 支持 `resourcepacks`、`shaders`、`schematics`。复用模组的移动、精确收据、双哈希、安装清单同步、取消/失败回滚及冲突保护；不同类别使用 `.shou-content-trash/<目录>`，旧 `.shou-mod-trash` 和收据格式不变。
- 恢复保留已登记条目的角色字段与后续无关安装；未登记资源不凭空创建安装清单。目标被外部占用、收据或回收文件改变、路径越界/链接时拒绝恢复，不覆盖外来文件。
- UI 捕获实际单项/多选文件后确认；写入先取消并排空检查句柄。回收读取和恢复结果核对当前实例、目录与类别，离页结果不污染其它页面。恢复面板为单行，收起只隐藏列表，重新读取仍可恢复；没有永久清空入口。
- 已核实的模组/资源包/光影详情可进入现有版本页；资源/光影不套用模组加载器过滤。返回时验证原实例/目录/类别，保留原搜索；未知文件无伪造下载入口，无关项目打开会清除旧返回上下文。

接口与边界记录于 [CONTRACTS](../../CONTRACTS.md)。
