# Java 与下载设置交互调整

## Java

- 页面顶部常驻当前全局 Java 选择、路径或失效提示，并说明实例单独设置可覆盖全局选择。
- 自动模式默认折叠运行时列表；手动选择或路径失效时展开。提供恢复自动选择和管理列表入口。
- 证书自动修复开关即时保存；证书状态常驻，检查详情与修复工具默认折叠。首次展开或手动扫描才执行检查，不在进入页面时扫描。
- 同一组件内相同 Java 列表的检查结果缓存最多五分钟；手动扫描绕过缓存，修复/恢复后清除缓存。结果命中待处理项时展开详情。按钮根据所选条目是否可修复或恢复启停。

## 下载源

- 常规下载设置在前，自定义源紧随其后，aria2 位于页面末尾。
- 列表直接启停源、上移/下移；移动保留选中项并为本分类重新分配递增优先级。编辑源或添加源时展开高级参数，官方源隐藏地址字段，前缀替换源显示官方 URL 前缀。
- 模式开关即时生效，使用已保存的源配置；源列表和高级字段集中保存，顶部显示未保存状态。切换标签或返回页面保留草稿，校验失败时定位分类并展开编辑器。
- 启用自定义排序时，原文件来源、版本清单来源和 Mod 来源选项暂停使用并明确说明；其他常规下载设置仍可调整。
- 页面展示已保存的 Minecraft 文件顺序，并解释版本浏览优先完整清单、社团精选清单仅作备用；Mod 和加载器使用各自分类。

## aria2

- 未启用时默认折叠 RPC 详情；启用时展开。开关即时保存，启用使用已保存的地址和密钥。
- RPC 地址与密钥的草稿另行保存，显示未保存提示，页面重新加载事件不覆盖草稿；地址无效时展开编辑器并报告错误。

## 验证与边界

编译后的 WPF 回归覆盖排序与选择保持、草稿隔离、列表启停、模式切换及旧选项禁用、校验定位、Java 失效提示与自动选择、证书惰性检查和即时保存、aria2 配置生效及返回页面保留草稿。沿用下载源与 Java 证书核心测试，不改变下载路由或证书修复规则。

本机截图预览受会话离屏渲染空白帧影响，不能作为完整视觉验收依据；仍需实际窗口下补充高 DPI、深色主题和键盘导航的人工确认。没有使用真实 aria2 服务或改写已安装 Java 的信任库。
