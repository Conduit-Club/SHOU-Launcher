# SHOU-PCL v1.2.0 · zyf

本版基于 `dev` 准备候选发行，并通过 `dev → main` PR 审查。发布包使用 Windows x64、自包含单文件程序；基于开发分支的包标记为预发布。

## 更新内容

- 纳入 PCL-CE `dev` 截至 `f00b458e7bcf1368ea4e00148cf5db09bd1f5133`（2026-10-15）的 9 个更新提交。
- 新增模组关系页：查看依赖、缺失前置、版本不符、冲突及内嵌模组；禁用或删除时可选择连带处理依赖它的模组。
- 改进 MultiMC 整合包安装、JSON Patches、Java 兼容版本选择、实例图标与配置保存、LWJGL 支持库处理。
- 统一 Mod Loader 安装选择逻辑；修复自定义主页帮助跳转、ToolTip 显示及联机大厅公告错误提示；更新法语和日语翻译。
- 切换为社团独立维护流程：默认分支 `main`，开发分支 `dev`，旧历史迁移为维护者署名快照，保留代码来源与作者声明。
- 修正仓库改名后的构建条件与发行链接，兼容旧仓库发行链接；隔离原 CE 发布和 MirrorChyan 工作流。
- 版本 `1.2.0`，代号 `zyf`，元数据 code `526`，程序集版本 `1.2.0.0`。

## 验证与限制

- 本机 .NET SDK `10.0.401`，Beta / x64 主程序编译通过（0 错误，5391 条编译警告）；离线测试共 319 项，318 通过、0 失败、1 跳过（ChaCha20 硬件能力不支持）。
- 最终候选包的源码 SHA、SDK、架构及配置记录在 `BUILD-INFO.txt`，测试报告随候选发行准备。
- 登录、令牌刷新、Minecraft 启动、自动进服、大型整合包安装和模组连带处理仍需实际账户与游戏实例验证。
- 沿用社团自己的 Microsoft Client ID；未配置的外部服务凭据不因本次同步而变为可用。
- 未做 Authenticode 签名。ZIP 的 SHA-256 作为旁置 `.sha256` 文件提供。
- 历史标签迁移后的源码树保持不变；旧发行二进制仍记录其原始源码 SHA，参见 [历史说明](HISTORY.md)。
