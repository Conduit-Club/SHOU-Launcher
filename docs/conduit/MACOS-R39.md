# R39：拖入安装与实例模组管理

按旧 WPF 正式版 `8746ad26` 的 `FormMain.FileDrag`、`PageInstanceCompResource`、`ModLocalComp` 和 `MyLocalModItem` 核对交互，在既有 Core/Avalonia 中实现。旧 WPF 文件保持不变；未引入 WPF 运行时或更改 Java、游戏进程及 Mac 原生库补丁策略。

## 拖入安装

| 输入与上下文 | 本轮行为 |
|---|---|
| 单个 ZIP/MRpack，非实例资源页 | 自动识别并进入安装和游戏文件准备；无额外选择时直接继续。有可选文件、缺文件、无效/冲突名称时保留面板供处理；不自动启动游戏 |
| ZIP 内容、RAR 后缀 | 与旧版一样尝试按 ZIP 读取；不声称支持真正的 RAR |
| 当前实例资源包/光影页的 ZIP | 分别装入 `resourcepacks` / `shaderpacks`，刷新当前列表，不跳整合包页 |
| 模组文件 | 支持同扩展名的批量 JAR/LiteMod 及 `.disabled/.old` 包装；在模组页直接安装，在其它页面确认目标实例。安装时恢复启用状态，LiteLoader 文件继续核实加载器 |
| 同名模组 | 恢复旧 WPF 的替换语义，原 JAR 与精确清单另存 `.shou-mod-backups/local-import-*`；移除被替换文件的旧在线身份，再按实际新文件核对来源。复制失败/取消不覆盖原文件 |
| 同名资源包/光影 | 沿旧版分支拒绝同名覆盖，原文件保留 |
| 投影文件 | 支持同类型批量 `.litematic/.nbt/.schematic/.schem`，当前页直接导入，其它页确认实例 |
| 存档列表的 ZIP | 接入已有世界预检/导入服务，成功预检后继续安装；沿用当前已验证的世界格式和版本边界 |
| 本地文件 URI | 可接收浏览器提供的本地 `file:` URI；不把任意网页链接当作本机文件 |

目标实例在选择器/确认后重新核对。列表导入改用固定实例/类别快照；批量发生错误时明确报告已完成数量。移除单个本地内容文件 512 MiB 和实例列表静默 2,000 项截断；复制使用临时文件，枚举可取消，源复制期间变化会失败。归档本身的 R37-LIMITS 没有据此宣称完成。

## 模组管理

- 进入模组页后自动后台检查，不占用全局忙碌遮罩。进度、取消、离页/换实例/销毁后的迟到回调均有处理。实际写入前等待已取消的扫描关闭 JAR 句柄，兼顾 Windows 文件共享语义。
- 本地大小/SHA-1/SHA-512 与安装清单先核对。Modrinth 批量哈希识别，CF 已登记文件保留精确项目/文件身份，未登记文件增加官方 fingerprint 批量匹配；CF 身份仍独立核对 SHA-1 和大小。指纹使用与旧版一致的过滤空白 Murmur2，以两遍流式读取实现。
- 按实际哈希、大小、游戏版本、加载器、来源和目录配置隔离六小时元数据缓存；读取不延长原检查时间。自动检查复用缓存，手动检查强制重新查询；每次生成新的短期更新令牌。失败不计为最新版，项目图标/介绍失败不丢弃已经核实的更新。
- 原列表支持全部、启用、禁用、可更新、错误和重复筛选，显示数量，并与文字搜索组合。重复项综合本地 Mod ID 与官方项目 ID 判定，单边在线识别不会拆散已知重复项。
- 行内显示更新状态和更新入口；可查看新旧版本、更新日志及本地详情。补在线名称、介绍和图标；五种排序使用名称、文件名、创建时间、大小和已取得的分类标签。
- 选中后才显示批量工具栏。批量启停、更新、回收与恢复均接入；更新使用一次明确的操作提示，移除原先重复勾选确认。多个更新分别保留备份，失败项记录后继续其它项，结果显示成功/总数。
- 删除移入实例内回收目录，带文件双哈希与原清单条目。恢复核对实例、文件、冲突和清单变化；事务中途失败回退，既有文件不覆盖，恢复后保留诊断收据。未提供永久清空。
- 增加基础归档错误、重复 ID、声明的依赖 ID 和第一层内嵌 JAR 信息检查，以及 TXT/CSV 信息导出。未将它称为完整依赖兼容分析。
- 新增静态提示维护简体中文、繁體中文与 English；历史动态提示和全部旧词条的翻译仍按 R34-LANG-NEXT 保留。
