# v1.4.0 · lzj

潮涌核心社启动器的独立维护版本，基于 `dev → main` 稳定分支整合。版本代码为 `528`，正式包使用 Release 配置、Windows x64 自包含单文件程序，无需额外安装 .NET。

## 本次变化

- 清理原 CE 遥测、旧账号与远程公告、更新等服务入口；联机改用本地配置的节点和会话内随机标识，保留必要的许可证及来源说明。
- 修复下载源优先级与版本列表回退：浏览游戏版本优先使用完整清单，社团精选清单仅作备用；保存源配置后失效旧缓存。
- Java 设置常驻当前选择摘要，自动选择时折叠运行时列表，手动选择或路径失效时展开；证书详情按需检查，修复与恢复按钮根据状态启停。
- 下载源可直接启停、上移、下移；高级参数按需展开，未保存草稿与实际生效配置分别提示。启用自定义源时明确禁用冲突的旧选项。
- aria2 详情随启用状态展开，保留未保存的 RPC 地址和密钥草稿，支持连接检查。
- 修整本次改动相关的构建警告；修复版本比较测试对固定“当前版本”的依赖。未对历史警告进行全局屏蔽。
- CI 产物文件名带版本、构建号与源码短 SHA；正式包使用 `SHOU-Launcher-win-x64-v1.4.0.zip`，附 SHA-256 文件和 `BUILD-INFO.txt`。正式发行工作流先验证标签来源、构建并通过回归测试，再生成草稿。

## 下载与登录

已配置 Microsoft 公共 Client ID。CurseForge 项目 API Key 仍待申请获批：Modrinth 不依赖该 Key；部分 CurseForge 请求可通过镜像回退，但仍受作者分发许可、镜像可用性与具体接口支持限制，不能保证所有 Mod 或整合包均可下载。

## 验证与已知限制

- 版本更新前的同内容候选包已通过云端 WPF 5 项、Java 信任库 19 项、社团 101 项、核心离线 356 项检查，以及 x64 / ARM64 编译；专项与全量测试存在重叠，不相加作为独立用例数。
- v1.4.0 的本机 Release 自包含构建成功，Release 配置的 WPF 5 项全部通过，核心离线 356 项中 355 项通过、1 项因本机 ChaCha20 能力不足跳过，0 失败；后续云端结果以对应 Actions 记录为准。
- 已对下载后的候选 EXE 内嵌程序集进行本机离屏验证：9 组检查、19 次控件点击、22 张截图，覆盖 Java、证书工具、下载源、aria2、联机设置及相关页面。新版 Release 的构建记录、测试结果和包哈希随正式发行补充。
- 离屏验证使用隔离配置、测试 Java 信任库和本机 RPC 模拟服务，不改写用户已安装 Java 的信任库；截图包括深浅主题、不同宽度与 150% 导出比例，不能替代真实高 DPI 显示器、键盘导航和完整游戏启动验收。
- 真实 Microsoft 登录、Minecraft 安装与启动、两端联机仍需服务联调；ARM64 仅完成交叉编译，未做真机验证。
- 程序未作 Authenticode 签名；SHA-256 用于核对包完整性。正式源码 SHA、SDK、架构与配置以发行包内的 `BUILD-INFO.txt` 和发行记录为准。
