# 社团视觉素材

本目录使用潮涌核心社网站现有素材，2026-10-02 获取，用于社团启动器品牌与首页轮播。

- `club-logo.png`：https://conduit-club.github.io/img/brand/velocity-server-icon.png
- `campus-lake.jpg`：https://conduit-club.github.io/img/screenshots/shou/campus-lake.jpg
- `spawn-plaza.jpg`：https://conduit-club.github.io/img/screenshots/smp/spawn-plaza.jpg
- `spawn-statues.jpg`：https://conduit-club.github.io/img/screenshots/create/spawn-statues.jpg

`club.ico` 为原图标按最近邻缩放生成的 16/32/48/64/128/256 像素 Windows 图标，`club-splash.png` 为 256 像素启动图，不改动原画面内容。首页直接加载内置实景图片，通过 WPF 实时虚化、裁剪和淡入轮播，不在启动时联网下载。

素材归属原作者及社团；此处的社团使用不意味着另行授予第三方素材许可。
